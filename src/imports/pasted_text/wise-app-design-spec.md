You are a Senior Product Designer, UX Researcher, and UI Designer from Apple, Google Material Design, and Notion.

Design a complete HIGH-FIDELITY responsive web application prototype for a thesis project called:

WISE
(Working Student Intelligent Support Engine)

This is NOT a generic productivity application.

This is an AI-powered Productivity Monitoring, Fatigue Prediction, and Recommendation System designed specifically for Working Students of the University of Northern Philippines.

The design should feel like a modern SaaS platform mixed with Apple Health, Google Material 3, Notion, Headspace, and Microsoft Fluent Design.

======================================================
DESIGN GOALS
======================================================

The application should make students feel:

• Calm
• Supported
• Motivated
• Organized
• Safe
• In Control
• Less Stressed

Avoid looking like:

❌ Cryptocurrency apps
❌ Gaming dashboards
❌ Hacker interfaces
❌ Neon AI websites
❌ Corporate ERP software

Instead, create a relaxing academic productivity experience.

The interface should feel like a wellness coach instead of a strict productivity tracker.
